# HVC Trikot-Abstimmung

Dies ist eine interne Abstimmungsseite für das Volleyballteam **HVC**.  
Die Seite ermöglicht es Teammitgliedern, verschiedene Trikotdesigns anonym zu bewerten.  
Alle Stimmen werden lokal im Browser gespeichert und können im Trainerbereich ausgewertet werden.

## Funktionen
- Bewertung von 7 Designs (A–G)
- Passwortgeschützte Abstimmung („HVC“)
- Trainerbereich mit Passwort („hvc2025“)
- Durchschnittsberechnung und Stimmenübersicht
- Bildvorschau der Designs
- Reset-Funktion für Trainer

## Nutzung
Diese Anwendung ist ausschließlich für das **HVC‑Volleyballteam** bestimmt.  
Sie ist nicht für die öffentliche Weitergabe oder kommerzielle Nutzung vorgesehen.
